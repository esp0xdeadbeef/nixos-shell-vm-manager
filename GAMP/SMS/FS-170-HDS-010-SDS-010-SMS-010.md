# FS-170-HDS-010-SDS-010-SMS-010 Read-only Attachment Primitives

Attachment uses `qemu-nbd --read-only --format <fmt> --connect <dev>` on a free
NBD device, chosen by reading `/sys/block/nbd*/pid` and `size`. Readiness is
confirmed by polling the device size.

Root discovery enumerates partition offsets with `parted -s -m ... unit B print`
and probes each candidate offset with `blkid --probe [--offset N] --output
export`. With no partition table the whole device is probed. Selection prefers
a Linux root filesystem labelled `nixos`, then any Linux root filesystem, and
never selects a FAT partition.

Mounting uses `mount -t <fstype> -o ro,nosuid,nodev,noexec[,offset=N]`.
Extraction without mounting uses `debugfs` `stat`/`dump`/`rdump`, addressing a
filesystem inside a partition with `?offset=N`; `rdump` reproduces guest
ownership, so extraction success is judged by the presence of extracted files
rather than by its exit status.

Releasing uses `umount` followed by `qemu-nbd --disconnect`, in that order, so
no mount outlives its backing device.
